## 🎨 Key Files to Know

### You Will Edit:
- **src/constants/data.js** - Your personal information

### You Will Add:
- **public/assets/profile.jpg** - Your photo
- **public/assets/resume.pdf** - Your resume

### You Might Edit:
- **tailwind.config.js** - Change accent color
- **index.html** - Update meta tags

### Don't Edit (Unless you know what you're doing):
- Component files (unless customizing)
- Configuration files (vite, postcss)
- Package files

### First Time Setup
```

```
