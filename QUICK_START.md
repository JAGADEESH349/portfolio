# ⚡ Quick Start Guide

## 🎯 In 3 Minutes, Get Your Portfolio Running!

### Step 1️⃣: Install (30 seconds)
```bash
npm install
```

### Step 2️⃣: Add Assets (1 minute)
Place these files in `public/assets/`:
- ✅ `profile.jpg` - Your photo
- ✅ `resume.pdf` - Your resume

### Step 3️⃣: Start (10 seconds)
```bash
npm run dev
```

### Step 4️⃣: Open Browser
Go to: **http://localhost:5173**

---

## 🎨 Customize in 5 Minutes

Open `src/constants/data.js` and update:

### 1. Personal Info
```javascript
name: "Your Name"
title: "Your Title"
tagline: "Your tagline"
```

### 2. Social Links
Update URLs to your profiles

### 3. Skills
Add/remove skills as needed

### 4. Projects
Update with your actual projects

### 5. Experience
Add your work history

**Save and watch it update live!** 🔥

---

## 🚀 Deploy in 2 Minutes (Netlify)

1. Push to GitHub:
```bash
git init
git add .
git commit -m "My portfolio"
git remote add origin YOUR_REPO_URL
git push -u origin main
```

2. Go to [netlify.com](https://netlify.com)

3. Click "Import from Git" → Select repo

4. Click "Deploy" (settings auto-detected)

5. **Done!** Your site is live! 🎉

## ⚠️ Common Issues

**Images not showing?**
→ Check file names: `profile.jpg` (lowercase)

**Styles broken?**
→ Run `npm install` again

**Port already in use?**
→ Use: `npm run dev -- --port 3000`
